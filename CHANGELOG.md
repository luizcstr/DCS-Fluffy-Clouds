# Changelog

## Weather MSFS Realistic Standalone

Replaced the previous Fluffy Clouds 1.0 release contents with the complete standalone package.

### Included changes

- Bundled the ATMOS-X shader and terrain files required for standalone operation.
- Updated cloud presets, cloud coverage, cirrus, sky, precipitation, water, lightning, and particle effects.
- Included the standalone `fxo.edcz` shader cache and complete effect texture archive.
- Added the Mission Editor weather files and cloud thumbnails from the source package.
- Translated the repository documentation and installation notes into English.
