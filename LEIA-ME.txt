DCS Fluffy Clouds — STANDALONE MOD
==================================

WHAT IS INCLUDED
  - Reworked ATMOS-X cloud presets and terrain configuration.
  - Required ATMOS-X renderer and shader files bundled into one mod.
  - Patched volumetric-cloud shader cache, cloud map, cirrus, sky,
    precipitation, water, lightning, and particle shaders.
  - enlight.dll for both bin and bin-mt.
  - Effect textures, cloud thumbnails, and Mission Editor integration.

HOW TO ENABLE
  1. Close DCS.
  2. Disable ATMOS-X and any other cloud, weather, or shader mod that
     overwrites the same files.
  3. Confirm that the OvGME profile points to the DCS installation folder.
  4. Enable only "Weather_MSFS_Realista_Standalone".
  5. Start DCS and wait for the first shader compilation to finish.

FIRST LAUNCH
  DCS recompiles shaders the first time after the mod is enabled. This launch
  may take longer, and clouds may disappear and reappear while the cache is
  created. This is normal.

  Keep the same mod set active on later launches so the cache can be reused.
  If the pop-in continues after two launches without changing mods, close DCS
  and delete the "fxo" and "metashaders2" folders under Saved Games. DCS
  recreates both folders automatically.

REVERSAL
  Close DCS and disable "Weather_MSFS_Realista_Standalone" in OvGME. The
  manager restores the simulator's original files.
