WEATHER MSFS REALISTIC — STANDALONE
===================================

WHAT IT IS
----------
This is a self-contained standalone version. It includes the ATMOS-X shader
files required by the packaged fxo.edcz (atmARPCOverrides.hlsl,
atmARPCConstants.hlsl, atmDefinitions.hlsl, atmPrecompute.fx, droplets, water,
aurora, precipitation, and particle files), the Config\\terrain\\ATMOSX*.lua
files, graphics.lua, the patched fxo, cloud presets, cirrus, cloud map,
enlight.dll, and Mission Editor files.

ATMOS-X does not need to be enabled separately. Do not enable this package
together with ATMOS-X or the older Weather_MSFS_Realista_Completo mod.

HOW TO USE (OvGME)
------------------
1. Disable ATMOS-X in its application or in OvGME.
2. Disable Weather_MSFS_Realista_Completo.
3. Enable only Weather_MSFS_Realista_Standalone.
4. Start DCS and load a mission.

FIRST LAUNCH
------------
The first mission after changing mods causes DCS to recompile shaders once.
The slow loading screen may take several minutes; this is normal. Later loads
should be faster.

For a clean rebuild, optionally close DCS and delete the contents of:
  C:\Users\\<username>\\Saved Games\\DCS.openbeta\\fxo
  C:\Users\\<username>\\Saved Games\\DCS.openbeta\\metashaders2

REVERSIBLE
----------
Everything is managed through OvGME. Disable this mod to return to the
previous state; the OvGME backup remains intact.

NOTE: the god-rays test (fxo MD5 1e2471fe) is not included. This package uses
the approved fxo (MD5 9cc7edb2) and restores the approved cloud appearance.
